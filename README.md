# Музыкоиск

Android-поисковик аудиозаписей, Kotlin + Jetpack Compose.

## Статус v0.1.1
- Поиск по Internet Archive (только страницы записей, без прямых загрузок).
- Адаптер Jamendo с проверкой `audiodownload_allowed`; требует официального developer client ID и пока отключён (пустой ID).
- Параллельный движок, тайм-ауты, отмена поиска, базовый Compose UI.
- Чарты, загрузчик и локальная медиатека пока не реализованы.
- APK не собран, компиляция на CI не проверена.

## Сборка
Откройте проект в Android Studio (JDK 17, Android SDK 35), выполните Gradle Sync и соберите модуль app. Для воспроизводимых CI-сборок требуется добавить Gradle wrapper.

## Правила
Не обходить DRM, платный доступ или регистрацию. Если разрешение на загрузку не подтверждено, показывать страницу источника, а не прямую кнопку скачивания.
