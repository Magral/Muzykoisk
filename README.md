# Музыкоиск

Android-приложение на Kotlin и Jetpack Compose для поиска и загрузки музыки без перехода в браузер и без регистрации пользователя.

## Активный источник

Сейчас поиск использует Internet Archive. В результатах показываются только записи, для которых найдены прямой MP3-файл и подходящая лицензия. Переходы на страницы источников, чарт с недоступными файлами и каталоги без прямой загрузки удалены из приложения.

Перед загрузкой приложение проверяет метаданные записи. Поддерживаются CC0, Public Domain Mark, CC BY и CC BY-SA. Неизвестные и ограничительные статусы скрываются из результатов; защиту и вход в аккаунт приложение не обходит.

## Возможности

- Загрузка MP3 запускается в приложении, а её статус и прогресс доступны во вкладке «Загрузки».
- Файлы сохраняются в `Музыка/Muzykoisk` через Android DownloadManager.
- «Моя музыка» хранит избранные записи и параметры доступной загрузки между запусками.
- Поиск ограничен доступными прямыми MP3-файлами; результаты могут быть уже, чем каталоги коммерческой музыки.

## Сборка и релиз

Нужны JDK 17, Android SDK 35 и Gradle 8.9. GitHub Actions выполняет unit tests, собирает APK, проверяет подпись и публикует релиз при push в `main`. Версия релиза берётся из `app/build.gradle.kts`.
